    VÉLOCITÉ

    Une arène de canyon pour enchaîner glissades, bhops, tap-strafes et superglides. Entraîne-toi sur les robots, puis invite tes potes avec un code de partie.

    Sur mobile : joystick à gauche, glisse le doigt à droite pour viser. Joue en mode paysage.

    Sur iPhone, pour jouer en plein écran : bouton Partager de Safari → Sur l’écran d’accueil, puis lance Vélocité depuis l’icône.

    Le clic verrouille la souris. Échap met en pause.

    Personnage

    C’est le personnage que les autres joueurs voient en ligne.

    Un fichier .glb de 4 Mo max. S’il a un squelette Mixamo, il reprend les animations du jeu ; sinon il utilise ses propres animations (idle, walk, run). Les autres joueurs le voient en ligne.

    Multijoueur

    OU
    Signaler un joueur
    Partie en pair-à-pair : celui qui crée la partie l'héberge, les autres entrent son code.

    Réglages

    Viseur

    Chat vocal de proximité

    On entend les joueurs à moins de 45 m, plus fort quand ils sont près. Le chat écrit (Entrée) est aussi de proximité par défaut (Tab dans la barre pour écrire à tous).

    Manette

    Clique sur un bouton puis appuie sur le bouton de la manette à utiliser (Start annule).

    Stick gauche : bouger · stick droit : viser · A : sauter · B : glisser · X : recharger ou interagir · Y : arme suivante · LB/RB : capacités · LT/RT : viser/tirer · L3 : sprint · R3 : couteau · croix : emotes (haut), grenade (bas), arme précédente (gauche), type de grenade (droite) · Start : pause.
